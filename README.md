# my-scratch-project
Do not use this! I'm using this repository to share my project with specific other people. You can still check it out if you want though.

WASD or arrow keys to move around. W, Up arrow, or Space to jump. You can wall jump and you can hold on to the edge of a cliff. The large flame icons are save points, and the green ones are collectables. (I hid the score variable for now) Keys open doors. Be careful, you could get crushed by moving platforms and doors. Oh, and there are spikes and lava too. 

Press P to pause (New feature!)
